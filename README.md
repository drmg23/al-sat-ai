# AL-SAT WEB Başlangıç Projesi

## Kurulum

1. Bilgisayarınıza Node.js kurun.
2. Bu klasörü açın.
3. Klasörün içinde terminal açın.
4. Aşağıdaki komutları sırayla çalıştırın:

```bash
npm install
npm run dev
```

5. Tarayıcıda şu adresi açın:

```text
http://localhost:3000
```

## İçerik

- Next.js App Router
- TypeScript
- Tailwind CSS
- Mobil uyumlu ana sayfa
- Arama alanı
- Kategori kartları
- Örnek ilan kartları
- Ücretsiz ilan verme butonu
